## 📖 Overview

The modern web has historically been constrained to 2D flat rectangles, vertical feeds, and repetitive scroll mechanics. **AetherSphere 3D** transforms the web browser into an interactive hyper-dimensional portal.

Experience five procedurally generated dimensions with smooth 60+ FPS performance, real-time raycasting inspection, dynamic particle systems, customizable shader parameters, and generative spatial synthesizers.

## 🎮 Interactive Controls & Flight Modes

AetherSphere 3D offers 3 fluid camera navigation paradigms:

### 1. 🔄 Orbit Mode (360° Inspection)
- **Left Click + Drag**: Rotate around the realm focus point.
- **Scroll Wheel**: Smooth zoom in and out.
- **Right Click + Drag**: Pan viewport position.
- **Auto-Rotation**: Smooth continuous rotation around the celestial center.

### 2. 🚀 Free Drone Flight (WASD / First-Person)
- <kbd>W</kbd> / <kbd>S</kbd>: Fly Forward / Backward
- <kbd>A</kbd> / <kbd>D</kbd>: Strafe Left / Right
- <kbd>Q</kbd> / <kbd>E</kbd> or <kbd>Space</kbd> / <kbd>Shift</kbd>: Ascend / Descend
- **Mouse Aim**: Look in any direction in full 3D space with momentum damping.
- **Adjustable Velocity**: Dial flight speeds up to 35 m/s in the Creative Studio.

### 3. 🎬 Cinematic Waypoint Tour
- Autonomous director mode cycling between choreographed camera angles, panoramic fly-throughs, and narrative lore waypoints.

### 4. 🧘 Zen Immersion Mode
- Strips away all UI chrome and HUD overlays for a clean, distraction-free visual experience.

### 5. 🔍 Quantum Raycasting & Lore Inspection
- Click on any landmark object (Nexus Cores, Aurelia Prime, 4D Torus, Dyson Swarm Rings) to open the **Quantum Inspection Dossier**, examine telemetry data, and trigger harmonic resonance energy pulses.

## 🎛️ Real-Time 3D Engine & Shader Studio

Fine-tune the rendering engine live using the built-in **Creative Studio Modal**:
- **Simulation Speed**: Scale animation clock rates from `0.2x` slow-motion to `2.5x` hyper-speed.
- **Drone Camera Speed**: Configure flight thruster velocities from `5 m/s` to `35 m/s`.
- **Procedural Synth Volume**: Real-time master gain slider with instant mute toggle.
- **Wireframe Rendering**: Toggle WebGL wireframe geometry mode to inspect poly meshes and vertices.
- **Real-Time Telemetry HUD**: Live FPS counter, frame time delta (ms), active geometry count, triangle count, and draw calls.

## 🎵 Generative Procedural Audio Engine

AetherSphere 3D features a built-in zero-dependency procedural synthesizer built with the **Web Audio API**:
- **Zero External Audio Files**: 100% procedurally synthesized in real time.
- **Realm-Specific Soundscapes**:
  - *Cyberpunk*: Cyber synthwave minor 9th chords with dual saw and square wave harmonics.
  - *Celestial*: Ethereal crystalline Lydian harmonics tuned to 432Hz with lush sine waves.
  - *Abyss*: Deep sub-bass triangle wave drones with underwater low-pass filter LFO modulation.
  - *Kinetic*: Glassy pentatonic bell frequencies with crisp resonance.
  - *Solaris*: Warm plasma sub-harmonics and magnetic drone pulses.
- **Dynamic Interactive SFX**: UI clicks, dimension warp transitions, and energy pulse wave resonances.

- **Core Engine**: [Three.js](https://threejs.org/) (WebGL 2.0, ACESFilmic Tone Mapping, Additive Particle Systems)

- **Build Tool**: [Vite 6](https://vitejs.dev/)
- **Styling & HUD**: [Tailwind CSS v4](https://tailwindcss.com/) + Glassmorphism Backdrop Blurs

- **Icons & Effects**: [Lucide React](https://lucide.dev/) & [Canvas Confetti](https://github.com/catdad/canvas-confetti)

## 🚀 Quick Start

### Prerequisites
- [Node.js](https://nodejs.org/) (version 18+ recommended)
- [npm](https://www.npmjs.com/) or [bun](https://bun.sh/)

### 1. Clone the Repository
```bash
git clone https://github.com/Chithra582/AetherSphere-3D.git
cd AetherSphere-3D
```

### 2. Install Dependencies
```bash
npm install
```

### 3. Start the Development Server
```bash
npm run dev
```
Open your browser and navigate to `http://localhost:3000`.

### 4. Build for Production
```bash
npm run build
npm run preview
```
